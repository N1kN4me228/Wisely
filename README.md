# Wisely

Десктопное приложение для школьников (PyQt6): темы по предметам, задания
с пошаговым разбором решения и проверка домашнего задания по фото через ИИ
(Gemini). Интерфейс на русском и казахском.

## Возможности

- Предметы → темы → задания, с прогрессом по каждой теме
- Пошаговый разбор решения (текст + формулы)
- Проверка решения по фото: сфотографировал тетрадь → ИИ сверяет с ответом
- Переключение языка интерфейса RU / QAZ
- Отдельный режим для учителя (прогресс учеников)

## Стек

Python 3, PyQt6, SQLite (`core/wisely.db`), matplotlib (рендер формул),
Google Gemini API (проверка решений), PyInstaller (сборка в `.exe`).

## Запуск из исходников

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

pip install -r requirements.txt
```

Создайте файл `.env` в корне проекта:

```
GEMINI_API_KEY=ваш_ключ
```

Без ключа приложение всё равно запустится — просто проверка по фото будет
недоступна, остальной функционал работает.

Запуск:

```bash
python ui/main.py
```

## Сборка .exe

```bash
build_windows.bat     # Windows
./build.sh            # Linux/macOS (соберёт бинарник под свою ОС)
```

Готовый файл — `dist/Wisely.exe`. Если в корне проекта есть `.env`,
скрипт сам скопирует его в `dist/` рядом с `.exe`, чтобы ИИ-проверка
работала сразу после распаковки, без ручной настройки.

**Важно:** ключ при этом не зашивается в сам `.exe` — он лежит рядом
отдельным файлом. Не выкладывайте `dist/.env` с боевым ключом в открытый
доступ.

## Структура

```
ai_engine.py         # обращение к Gemini API, проверка решений
core/                # БД, модели, репозиторий, сидинг контента
ui/
  main.py            # точка входа
  pages/             # экраны приложения
  widgets/           # переиспользуемые виджеты (карточки, сайдбар, маскот)
  localization/       # переводы RU/QAZ
  resources/          # иконки, шрифты, стили, маскот
Wisely.spec          # конфиг PyInstaller
```
