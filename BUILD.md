# Wisely: запуск и сборка на Windows

## Запуск готовой версии

Для обычного Windows-ПК используется файл `dist\Wisely.exe`. Рядом с ним создайте файл `.env`:

```text
GEMINI_API_KEY=ваш_ключ
```

Ключ не нужно записывать в исходники или в `.exe`. Программа также принимает ключ из системной переменной окружения `GEMINI_API_KEY`. Рабочая база данных упакованной версии хранится в `%USERPROFILE%\Wisely\wisely.db`.

## Сборка на Windows

Сборку Windows нужно выполнять на самом Windows-ПК, потому что PyInstaller не делает настоящий Windows `.exe` из Linux. Установите Python 3.11+ с сайта python.org и включите **Add Python to PATH**.

Затем распакуйте проект и дважды щелкните `build_windows.bat` либо выполните в командной строке:

```bat
py -3 -m pip install -r requirements.txt pyinstaller
py -3 -m PyInstaller --noconfirm --clean Wisely.spec
```

Результат появится в `dist\Wisely.exe`. Сценарий `build_windows.bat` сам проверяет Python, устанавливает зависимости и запускает сборку без консольного окна приложения.

## Разработка без API

Для локальной проверки интерфейса без сети можно установить `WISELY_MOCK=1`. Во время реального анализа preloader отображается до ответа AI, а сетевые, квотные и ошибки ключа показываются безопасно, без API-ключа и traceback.
