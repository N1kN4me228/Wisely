# Финальная проверка Wisely на Windows

Эту проверку нужно выполнить на Windows-ПК, потому что текущая среда Linux не может подтвердить запуск настоящего Windows `.exe` на чистом компьютере.

1. Установить Python 3.11+ и включить `Add Python to PATH`.
2. Распаковать архив исходников.
3. Запустить `build_windows.bat`.
4. Убедиться, что появился `dist\Wisely.exe`.
5. Скопировать `dist\Wisely.exe` в отдельную пустую папку.
6. Рядом создать `.env` с `GEMINI_API_KEY=...`.
7. Запустить `.exe` двойным щелчком.
8. Проверить выбор русского языка и казахской латиницы.
9. Проверить карточки предметов и наличие Окто рядом с предметами.
10. Открыть задание, проверить правильный и неправильный ответы: Окто должен менять эмоцию.
11. Загрузить фото решения: во время анализа должна быть анимация preloader, после ответа — эмоция Окто по результату.
12. Проверить ошибку с временно неверным ключом: должен отображаться безопасный текст без ключа и traceback.
13. Проверить, что после перезапуска база создается/обновляется в `%USERPROFILE%\Wisely\wisely.db`.
14. На мониторе с масштабированием Windows 125% и 150% убедиться, что кнопки, маскот и тексты не обрезаются.

Ожидаемый результат: приложение запускается без консольного окна, UI не падает при смене языка, AI-ошибки безопасны, а `.env` не включается в архив сборки.
